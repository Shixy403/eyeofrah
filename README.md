# Eye of Rah – Auto Battler Game inspired by Super Auto Pets (C++)

Developed as part of a team project at DigiPen Institute of Technology.  
Eye of Rah is a 2D auto-battler inspired by *Super Auto Pets*, featuring turn-based combat, traits, and team-building mechanics.

## 🧠 Overview
Eye of Rah was built using **C++ and RapidJSON** for data-driven unit behavior.  
Gameplay centers around assembling a team of units with synergistic traits and battling AI-controlled opponents.

## 🧩 My Contributions
- Developed and maintained the **Combat System** for turn-based auto battles.  
- Implemented the **Trait System** for unit synergies using JSON configuration files.  
- Built **CombatPreparation** and **Team Management** modules for modular game flow.  
- Added **game balance and economy adjustments**, improving playability and pacing.  
- Designed and implemented **UI elements** such as victory text boxes, shop interactions, and settings.  
- Integrated RapidJSON for dynamic data loading (units, traits, and stats).  
- Performed bugfixing, warnings cleanup, and documentation.
